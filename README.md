# 樂在齡中｜數獨小教室 v96

本版以 v93 為基礎，僅調整 6×6「困難」隨機題產生器的搜尋上限與執行方式。

## 本次修改
- 6×6 困難模式恢復隨機產生，不使用固定題。
- 搜尋上限由 1,800 次提高為 18,000 次。
- 每 100 次搜尋讓出瀏覽器主執行緒，避免搜尋時整個網站凍結。
- 搜尋期間顯示進度；找到合格題目後才進入棋盤。
- 題目仍須符合唯一解，且不能只靠裸單數／隱性單數解完整盤。
- 保留 v93 的燒腦之一、燒腦之二固定題與其他功能。
- 未修改 1～26 步教學題目、輸入函式、事件綁定與 50 步復原／重做程式。

## 驗證
- `node --check js/app.js`：通過。
- ZIP 完整性：通過。
- 與 v93 比對：除困難隨機產生器、其非同步呼叫方式、困難搜尋進度與快取版本號外，其他程式保持一致。
- 尚未完成真實 iPhone Chrome 與公開 GitHub Pages 實測。

## 部署
解壓後將 ZIP 內檔案直接覆蓋網站專案對應檔案，確保 `index.html`、`js/`、`css/`、`assets/` 都在網站根目錄。
