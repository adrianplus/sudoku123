# 樂在齡中｜數獨 100 步（第一步：網頁外殼）

## 目前包含
- 首頁與品牌標題
- 100 步學習地圖（以 10 個章節呈現）
- 可點選的章節入口與教學佔位畫面
- 手機、平板、電腦響應式版面
- 放大文字按鈕
- 基本鍵盤焦點與跳至主要內容連結

## 目前尚未包含
- 真正的數獨答題互動
- 100 個細分關卡
- 進度儲存
- 正式數獨答案驗證

## 如何執行
最簡單的方法：解壓縮後，直接用瀏覽器開啟 `index.html`。

如果某些瀏覽器限制本機檔案功能，可使用 VS Code 的 Live Server，或部署到 GitHub Pages 等靜態網站服務。

## 測試清單
1. 開啟 `index.html`，確認首頁正常。
2. 點選「開始我的第一步」，確認進入教學佔位畫面。
3. 點選「回到學習地圖」，確認回到首頁與章節列表。
4. 點選不同章節，確認標題與說明更新。
5. 點選「放大文字」，確認文字變大，再點一次恢復。
6. 在手機寬度下測試，確認沒有橫向溢出，章節卡片改為單欄。
7. 使用鍵盤 Tab，確認按鈕可以被選取。
