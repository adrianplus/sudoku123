# 樂在齡中｜數獨新手村 v72

## 本版修正
- 修正 4×4 隨機數獨的筆記小字輸入與顯示流程。
- 筆記模式 ON 時，選取可編輯格並按 1～4，會在格內對應的 2×2 固定位置顯示紅色候選小字：1 左上、2 右上、3 左下、4 右下。
- 重複輸入同一候選數字可移除。
- 筆記模式 OFF 時，按數字仍以大字填入答案。
- 筆記模式下若選取格已有玩家輸入的大字，會先清除大字，再記錄候選小字。
- 新題開始時「空」按鈕在尚未選格前維持停用。

## 修改範圍
- `js/app.js`：整理 4×4 隨機遊戲的筆記輸入、格子重繪與選取狀態。
- `css/style.css`：明確設定 2×2 小字位置及顯示層級。
- 第 1～26 步教學內容、原始題庫、抽題挖空規則、檢查及完成流程未刻意修改。
