# 樂在齡中｜數獨新手村 v75

## 本版新增：4×4 數獨困難
- 困難難度保留 12 格空白，只顯示 4 個提示數字。
- 以第 11～13 步三道畢業考的完整解盤為來源，隨機選一題作為基礎。
- 對來源解盤進行合法數獨等價變形：數字重命名、同一橫帶內列交換、橫帶交換、同一直棧內欄交換、直棧交換及轉置。
- 隨機抽取 4 個提示位置；提示數字必須至少包含 3 種不同數字。
- 每題均以回溯解題器計算解的數量，只接受恰好唯一解的題目；若隨機抽樣未命中，會窮舉提示位置尋找合格題，不會以多解題目作為保底。
- 「提升難度」流程擴充為簡單→普通→困難；困難已是最高難度。
- 「再玩一題」維持目前難度。

## 修改範圍
- `js/app.js`：新增合法盤面變形、困難題四提示生成、至少三種數字限制、唯一解驗證，以及普通升級困難流程。
- `index.html`：更新 JS/CSS 快取版本號至 v75。
- 第 1～26 步教學內容、原始三道畢業考解盤、筆記工具列及既有遊戲操作未刻意修改。
