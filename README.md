# 樂在齡中｜數獨新手村 v24

本版以 v23 為基礎，更新第八、九步的文字與新增第九步實戰模式。

## 第八步：4X4數獨練習
- 使用固定的 4x4 經典題目。
- 依序解開指定的六格，每次答對後保留答案。

## 第九步：4X4數獨實戰
- 使用相同題目，不顯示問號提示。
- 先點選空格，再按 1、2、3、4 填入數字。
- 按「檢查」只檢查已填入的格子；錯誤數字標紅，不直接顯示正確答案。
- 全部填完且答案正確才完成本關。
- 右下燈泡依第八步「一、二、三、四、五、六」位置提供最多六個提示答案。

部署：將 index.html、css、js、assets 與 README.md 上傳至 GitHub 儲存庫並覆蓋同名檔案。


## 第十步：找到4X4數獨的破局點
- 共三張固定題目，使用者需自行選擇空格並填入數字。
- 第一張與第三張各有兩個可接受的破局點，任一答對即可過關；第二張只有一個指定破局點。
- 答對立即切換下一張；答錯的輸入以紅色標示，並請使用者重新尋找。
- 三張題目全部答對後完成本關。遊戲中不顯示星星或答案提示。
