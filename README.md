# 樂在齡中｜數獨新手村 v67（益智遊戲介面版）

## 本版目的
先完成「玩」益智遊戲專區的導覽與選單格式，暫不製作隨機出題及作答功能。

## 本版介面
- 頂部導覽列新增「玩」入口，紅色醒目呈現，略大於「主」按鈕。
- 「玩」入口開啟「益智遊戲」專區。
- 專區先放入「數獨隨機題目」入口，並保留「更多益智遊戲」的擴充位置。
- 進入數獨後，可選擇 4×4、6×6、9×9。
- 4×4 可選擇簡單（4格空白）、普通（8格空白）、困難（12格空白）。
- 選擇尺寸或難度後只顯示目前規劃狀態，不會開始出題；隨機題目與作答功能留待下一階段。

## 本次修改範圍
- `index.html`：更新遊戲專區說明與資源版本標記。
- `css/style.css`：調整遊戲入口、遊戲卡片、尺寸與難度選單的版面。
- `js/app.js`：難度選擇改為顯示「介面規劃中」提示，不啟動既有隨機題目流程。

## 保留項目
- 原有第 1～26 步教學內容及既有程式保留，未刻意修改。
- 原有隨機數獨程式碼仍留在檔案中，但本版選單不會啟動它。

## 檢查
- 已執行 `node --check js/app.js`，JavaScript 語法檢查通過。
- 尚未完成瀏覽器實際操作測試；請部署後檢查桌機與手機版版面。

部署方式：解壓縮後，將 ZIP 根目錄中的 `index.html`、`css`、`js`、`assets` 與 `README.md` 覆蓋上傳至 GitHub 儲存庫。
