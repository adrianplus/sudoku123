# v83｜錯誤答案需按檢查才標紅，且可修改／清除

以 v82 為基準，本版只調整 6×6 隨機數獨的答案檢查與玩家輸入格操作。

- 輸入數字時不立即判斷對錯；即使輸入明顯錯誤的數字，也先以正常顏色顯示。
- 只有按下「檢查答案」後，錯誤的玩家輸入格才會標紅。
- 被標紅的玩家輸入格可以再次點選，並用下方數字鍵直接改寫。
- 修改錯誤數字後，該格立即恢復正常顏色；需再次按「檢查答案」才重新判斷。
- 選取已輸入的玩家答案後，按「空」可清除數字及紅色標示。
- 題目原有數字仍不可修改或清除；點選題目原有數字仍可反金其橫排、直排與六宮格。
- 取消「最後一格填完後自動檢查」；完成輸入後由玩家自行按「檢查答案」。

修改檔案：
- `js/app.js`：6×6 隨機數獨增加「按檢查才標紅」狀態；玩家輸入格可選取、覆寫與清除；取消自動檢查。
- `index.html`：更新 JS 快取版本參數為 v83。

未修改：題目生成與唯一解檢查、難度設定、棋盤格線、數字完成反灰、筆記／提示、4×4遊戲及第1～26步教學。

檢查：`node --check js/app.js` 通過；ZIP 完整性檢查通過。尚未進行實際瀏覽器／手機操作測試，請下載後實測。
