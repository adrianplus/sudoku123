# 樂在齡中｜數獨小教室（第一階段互動版）

## 本版內容
- 第一步：橫排
- 第二步：直排
- 第三步：四宮格
- 每題隨機排列 1、2、3、4，隨機隱藏一個數字。
- 玩家選擇下方 1–4 作答。
- 答對連續累積 3 題即可完成本步；答錯會將連續答對數歸零。
- 完成第一步可直接進第二步；完成第二步可直接進第三步。
- 支援手機、平板、桌機；可切換放大文字。
- 不需登入、不計時。

## 更新 GitHub Pages
1. 解壓縮這個 ZIP。
2. 打開 GitHub 專案 `adrianplus/sudoku123` 的 Code 頁面。
3. 點 `Add file` → `Upload files`。
4. 把這個資料夾裡的 `index.html`、`README.md`、`css` 資料夾、`js` 資料夾拖到上傳區。
5. 確認 `index.html` 位於專案根目錄，而不是額外的子資料夾內。
6. 按 `Commit changes`。
7. 等待約 1–3 分鐘，再重新整理網站。

## 測試建議
- 橫排、直排、四宮格各完成連續三題。
- 故意答錯，確認連續答對數歸零。
- 使用手機打開網址，測試數字按鈕是否容易點選。
