# sudoku-v91-history-controls

以 v90 為基礎，新增 6×6 隨機數獨（簡單、普通、困難試作、燒腦試作）操作歷史功能。

## 新增功能
- 棋盤上方新增「上」「下」按鈕；初始時兩者皆不可按。
- 第一次輸入答案或增加/刪除候選筆記後，「上」啟用。
- 回到較早狀態後，「上」左側即時顯示「返回N步」；「下」可逐步恢復。
- 最多保留最近 50 個操作步驟（另保留一個起始狀態）。超過時淘汰最舊紀錄。
- 回到舊狀態後若新增操作，捨棄原本後續分支。
- 輸入/覆寫答案、增加/刪除候選筆記、清除答案或筆記，均各算一步。
- 開啟/關閉筆記模式、選取格子、數字反白/取消反白、按「上/下」均不算一步。
- 歷史狀態包含棋盤數字、候選筆記及檢查後的錯誤標示；選取狀態、反白及筆記模式開關不回溯。
- 原始題目數字仍不可修改或清除。

## 保護範圍
未修改第 1～26 步教學內容、4×4 隨機數獨、6×6 出題盤面與既有反白/筆記/檢查邏輯；僅新增 6×6 隨機數獨的操作歷史功能及必要 UI。
