# 樂在齡中數獨新手村 v80

## 本版修改
- 以 v79 為基準，只新增 6×6 隨機數獨的「空」按鈕取消反金功能。
- 當使用者點選棋盤上已有的數字、出現金色反白時，「空」按鈕會保持可按。
- 此時按下「空」，會清除目前的反金狀態，棋盤恢復一般顯示。
- 若已選取可編輯空格，按下「空」仍維持原本清除該格答案與筆記的功能。

## 保留
- v79 的 6×6 棋盤線條修正不變。
- 6×6 簡單（挖空7格）、普通（挖空14格）、唯一解檢查、反金、筆記、提示、自動檢查維持原樣。
- 4×4 遊戲及第1～26步教學內容未修改。
