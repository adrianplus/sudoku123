# V82 正式版：第三十三步－練習筆記小字（9×9橫排）

## 本版新增
正式新增第三十三步，共 6 題，練習 9×9 數獨橫排的候選小字。

### 六題固定結構
1. 第 1 題：同宮的橫排缺二。
2. 第 2 題：同宮的橫排缺二。
3. 第 3 題：非同宮的橫排缺二。
4. 第 4 題：非同宮的橫排缺二。
5. 第 5 題：同宮的橫排缺三。
6. 第 6 題：同宮的橫排缺三。

## 操作規則
- 第一題開始時，筆記模式為 OFF，玩家必須主動開啟「筆記」。
- 進入後續題目時，筆記模式維持 ON。
- 每個空格都要記下該橫排缺少的全部候選數字。
- 缺二題：每個空格都要記下相同的 2 個候選小字。
- 缺三題：每個空格都要記下相同的 3 個候選小字。
- 六題全部完成即可過關。

## 視覺與邏輯
- 使用完整 9×9 格子與九宮格粗框，讓「同宮／非同宮」的位置關係清楚可見。
- 題目只提供橫排資訊，避免加入直排或其他額外解題線索。
- 最外圍框線維持與九宮格分隔線相同粗度。
- 第 1～32 步已驗收功能不任意修改。

- 選取空格時以明顯藍色反白。
- 題目說明依目前題次顯示，不再一次列出六題規則。
