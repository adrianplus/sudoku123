# V81 正式版：第三十二步－找出真正有用的線索

## 本版新增
- 正式新增第三十二步「找出真正有用的線索」。
- 參考第七步的核心概念：在完整 9×9 棋盤中加入無關數字，練習判斷真正與答案有關的線索。
- 維持 5 題連續答對即可完成本關。

## 第三十二步出題規則
1. 題目由完整、合法的 9×9 數獨盤產生。
2. 問號所在的橫排、直排與九宮格中，提供 8 個不同數字。
3. 這 8 個數字剛好缺少唯一答案，因此可以推測出第 9 個數字。
4. 三個方向都會參與：橫排至少有一個線索、直排至少有一個線索，並保留至少一個只能透過九宮格觀察到的線索。
5. 另外在三個相關方向以外加入 8～12 個干擾數字。
6. 干擾數字全部取自同一盤合法數獨，因此不會破壞任何橫排、直排或九宮格的數獨規則。
7. 解題時只要鎖定問號所在的橫排、直排與九宮格；其他數字只是觀察干擾。
