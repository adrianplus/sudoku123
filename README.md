# 樂在齡中｜數獨小教室 v3

本版更新：
1. 右上角提供「小」「大」兩個按鈕，小在左、大在右。
2. 字體有四級：字體小、字體正常、字體大、字體特大；按一次調整一級。
3. 每步連續答對三題後，立即跳出完成視窗，讓玩家選「下一步」或「回到主頁」。
4. 第三步完成後隱藏「下一步」，避免點擊後沒有後續內容。

更新 GitHub Pages：
1. 解壓縮 ZIP。
2. 到 https://github.com/adrianplus/sudoku123 的 Code 頁面。
3. 點 Add file → Upload files。
4. 上傳並更新 index.html、css/style.css、js/app.js（README.md 可一併更新）。
5. 確認 index.html 在專案根目錄，按 Commit changes。
6. 等待約 1–3 分鐘後重新整理網站。
